## Selected work

### [O’Limpide Verdon](https://www.olimpide-verdon.fr/)

A website presenting canyoning, climbing and via ferrata activities in the Verdon, in southern France.

**My role:** Website development. I built the site with **Next.js and React**, using **Payload CMS** to manage its content.

[Explore the website](https://www.olimpide-verdon.fr/) · [Read about the project](https://gilles.mastropasqua.fr/projects/olimpide-verdon/)

### [EquiGenes](https://www.equi-genes.com/)

A multilingual equine genetics application combining an interactive coat colour calculator with accessible educational content about horses.

**My role:** Application development with **Next.js and React**, using an AI-assisted workflow with **OpenAI Codex**.

[Explore EquiGenes](https://www.equi-genes.com/) · [Read about the project](https://gilles.mastropasqua.fr/projects/equigenes/)

### [TET Atlas](https://atlas.transeurotrail.org/)

An interactive map for exploring the Trans Euro Trail, a network of adventure motorcycle routes across Europe.

**My role:** **Co-creator and volunteer developer.** I built the initial prototype, then developed the first versions of TET Atlas with **Lucas Gabriel Salina D’Ovidio**, a fellow developer and TET volunteer. My work included the early interfaces with Next.js and React, and processing GPX files for display on the map. Like the rest of the TET team, we contributed as volunteers. After those first versions, Lucas continued developing and improving the Atlas on his own.

[Open TET Atlas](https://atlas.transeurotrail.org/) · [Read about the project and my role](https://gilles.mastropasqua.fr/projects/tet-atlas/)
